# Check whether recent reasoning or activity has stalled or become repetitive

Review the following sequence of thoughts, actions, or attempts.

Recent activity:
{recent}

Answer directly:
1. Is there a pattern of repetition? Name it specifically if yes.
2. Has meaningful progress been made since the start? Yes or no — what is the evidence?
3. If stuck: what is the actual blocker — not the symptom, the underlying cause.
4. One concrete next step to either break the pattern or confirm it is resolved.

Be blunt. One or two sentences per point. Do not soften the assessment.
